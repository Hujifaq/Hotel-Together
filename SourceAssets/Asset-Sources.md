# ที่มาของโมเดล

HotelTogether-*.glb: โมเดลที่สร้างระหว่างงานในแชตนี้

Imported-* เป็นโมเดลที่ผู้ใช้ส่งมา: Cleaning/TinyLiving/Washing และ Toilet/Paper/Janitor/Furniture/Window/Electric ชื่อโมเดลต้นทางและเงื่อนไขอนุญาตต้องตรวจจากหน้าที่ผู้ใช้ดาวน์โหลด ข้อมูลในแชตยังไม่มี URL ผู้สร้างหรือใบอนุญาต จึงไม่ได้สมมติว่าอนุญาตเชิงพาณิชย์
