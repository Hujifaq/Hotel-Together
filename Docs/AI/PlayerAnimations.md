# แอนิเมชันตัวละครและท่าทางการทำงาน

เพิ่มวันที่ 13 ตุลาคม 2026 บน Unity 6000.6.5f1 ใช้ skeleton และ mesh ของ Bellhop / Housekeeping เดิม ไม่เพิ่มแพ็กเกจหรือเปลี่ยน scene/prefab

## ท่าที่เชื่อมกับเกม

| กลุ่ม | ท่าทาง |
| --- | --- |
| เคลื่อนไหว | ยืนพักและหายใจ เดิน วิ่ง เลี้ยว ตก นั่ง ลุก |
| สิ่งของ | เอื้อมหยิบ ถือมือเดียว/สองมือ วาง โยนและผ่อนแขนหลังปล่อย เข็น/ปล่อยรถ |
| งานบริการ | เอื้อมใช้งานประตู สวิตช์ กริ่ง ปุ่มลิฟต์ เช็กอิน โหลดและเสิร์ฟถาดอาหาร ส่งของ ใช้เครื่องซักผ้า ล้างไม้ถูพื้น |
| แม่บ้าน | จับด้ามไม้ถูพื้น ถูต่อเนื่อง ก้มลำตัว เก็บ/วางขยะ |
| ต่อสู้ | เตรียมและเหวี่ยงหมัด/อาวุธ ยกมือ/ไม้ตีป้องกัน รับความเสียหาย ก่อไม้ ถอนไม้ ซ่อม ใช้ยา ช่วยแขก ล้มและฟื้นตัว |
| แขก | เดินและถือกระเป๋า หายใจ/มองรอบตัว ก้มแกะกระเป๋า นั่ง กิน เรียกบริการ ยกแก้วดื่ม นอน/ตื่น หนี หลบภัย ล้มและฟื้นตัว |
| ซอมบี้ | เดิน ยกแขนโจมตี/พังช่องเปิด สะดุ้งเมื่อถูกตี ค่อย ๆ ล้มเมื่อพ่ายแพ้ |

งานที่เป็นการเอื้อมหรือกดปุ่มใช้ท่า interaction ร่วมกัน ไม่ใช่คลิปเฉพาะเครื่องมือทุกชนิด ท่าก่อไม้/ซ่อมเป็นการขยับมือ ไม่มีโมเดลค้อนใหม่ แอนิเมชันไม่เพิ่มงานที่ระบบ gameplay ยังไม่รองรับ

## วิธีทำงาน

`HotelPlayerAnimation.cs` เป็น presentation layer ของ partial `HotelPlayer` แยกสถานะต่อเนื่องออกจาก gesture ชั่วคราว อ่านสถานะถือของ รถเข็น ที่นั่ง งานถูพื้น และสุขภาพจากระบบจริง ท่าชั่วคราวมีจังหวะเข้า ลงมือ และกลับท่าพัก โดยความเสียหาย การเสิร์ฟ และฟิสิกส์ยังถูกตัดสินโดย gameplay เดิม

`HotelEmployeeRig` ต่อ skeleton เดิมด้วยการหายใจ จังหวะวิ่ง การเอียงตัวเมื่อเลี้ยว การเปลี่ยนท่านั่ง/ล้มแบบค่อยเป็นค่อยไป IK เท้าและมือยังทำงาน ท่านั่ง–ลุกไม่ตีความการย้ายตำแหน่งครั้งแรกเป็นก้าววิ่ง และรีเซ็ตประวัติท่าทางเมื่อเริ่มเกมใหม่

มือ first-person เดิมจาก `HotelBulkyHand.bytes` ใช้เป้าหมายท่าทางร่วมกับ arm IK แสดงมือแม้ไม่มีของเมื่อโจมตี ใช้งาน ป้องกัน หรือใช้ยา มือผ่อนกลับหลังปล่อยของ พร้อมขยับนิ้วและ blend ทิศทางท่าชั่วคราว ของที่ถือยังใช้จุดจับบนวัตถุจริง เพื่อไม่ให้มือออกจากด้ามหรือรถเข็น

การบล็อกด้วยไม้ตีเปลี่ยนตำแหน่ง/มุมของที่ถือผ่านระบบฟิสิกส์เดิม การโยนยังคืน layer, gravity และแรงส่งเดิม ไม่มี animation event ที่เป็นผู้ตัดสินผล gameplay และไม่มี root motion ใหม่

แอนิเมชันใช้เวลาเกม จึงหยุดพร้อมเมนู Esc ตัวผู้เล่น มือ และ NPC ไม่เดินแอนิเมชันต่อด้วยเวลานอกเกม การปิดหรือรีเซ็ตท่าทางคืนสถานะพักได้ โดยเก็บการเลือกพนักงานและค่าตั้งค่าเดิม

## การใช้งาน

เปิด HotelLobby แล้ว Play ได้เลย Component เดิมเชื่อมโค้ดใหม่โดยอัตโนมัติ ไม่มี Inspector wiring เพิ่ม ใช้ปุ่มเดิม: WASD / Shift / E / Q / Space / F / LMB / RMB / H / B / N / T และ G สำหรับรถ/อุปกรณ์ตามบริบท

## ผลตรวจและภาพตัวอย่าง

- Runtime และ Editor คอมไพล์ด้วย Roslyn ของ Unity และ references ของโปรเจกต์ ไม่มี compile errors คำเตือน obsolete APIs ของโปรเจกต์เดิมยังอยู่
- `HotelAnimationValidation.RunBatch`: ผ่าน 120 รายการตรวจด้วย prefab/mesh ของพนักงานจริงทั้งสองแบบ ได้แก่ gesture, การกลับท่าพัก, การขัดจังหวะ, pause, hold/cart/reach/mop/block/fall/down states และ vertex/bounds ที่ยัง finite พร้อมตรวจ pause ของแขก
- `HotelPlayerMenuValidation.Run`: ผ่าน 20 รายการใน Play Mode ด้วยมือเดิมจริง รวมตีมือเปล่า hand vertices การพักกลางท่า การจบท่า การผ่อนมือหลังปล่อยของ และ layer/gravity/แรงส่งของการโยน
- ชุดตรวจทำงานใน Unity project แยกที่คัดลอก Scripts, employee prefabs/art, hand resource และไลบรารีที่ตรงกัน ไม่เปิดหรือบันทึกฉากโรงแรมของผู้ใช้

รายงานใน workspace: `output/animation-qa/AnimationValidation.txt` และ `PlayModeValidation.txt` มีภาพแต่ละท่า `pose-sheet.png` และ `strike-preview.gif` ซึ่งเรนเดอร์จาก bone pose ของโค้ดจริง ภาพตรวจใช้มุม third-person และวัสดุ built-in เพื่อแยกการตรวจ skeleton ออกจาก shader import จึงไม่ใช่ภาพแสง/วัสดุของ HotelLobby เครื่องมือทดสอบใช้ props ขนาดจำลอง และไม่แสดงอุปกรณ์จริงใน pose sheet

## ขอบเขตที่ยังต้องตรวจ

ยังไม่ได้เล่นครบทุกงานใน HotelLobby จริง ตรวจ clearance ของมือกับเฟอร์นิเจอร์ทุกจุด วัด FPS สร้าง standalone build หรือทดสอบ multiplayer แอนิเมชันเป็น procedural skeleton/IK ไม่ใช่ชุด mocap/Humanoid clips หรือระบบ ragdoll ใหม่
