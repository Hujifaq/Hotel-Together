# HotelTogether

โปรเจกต์โรงแรม 3D สำหรับเปิดและพัฒนาต่อใน Unity

## เปิดโปรเจกต์

1. ติดตั้ง Unity Editor **6000.6.5f1** ผ่าน Unity Hub
2. Clone repository แล้วเลือก Add project from disk ใน Unity Hub
3. รอ Unity นำเข้าโมเดลและแพ็กเกจ
4. เปิด `Assets/HotelTogether/Scenes/HotelLobby.unity` แล้วกด Play → เข้าเล่น

ใช้ WASD เดิน, Shift วิ่ง, E ใช้งาน, Q วาง, Space โยน, R เริ่มใหม่ และ Esc เปิดเมนู

## สถานะล่าสุด

มีล็อบบี้ ห้องอาหาร ครัวและพื้นที่บริการชั้นหนึ่ง พร้อมระบบหยิบสิ่งของ เข็นรถ นั่ง เปิดโคมไฟ กดกริ่ง และเปิดประตู
ชั้นสองมีห้องพัก 16 ห้องและห้องบริการเป็นห้องเปล่า ดาดฟ้าแบ่งโซนตามแปลน บันได A/B เชื่อมครบทุกชั้น
ระบบออนไลน์ ลิฟต์โดยสาร และระบบงานบางอย่างยังไม่เสร็จ ดูรายละเอียดใน [README-TH.md](README-TH.md)

## ทำงานร่วมกัน

เก็บ Assets พร้อมไฟล์ .meta, Packages, ProjectSettings และ SourceAssets ไว้ใน Git
Library, Temp, Logs และตัวเกมที่ build แล้วไม่ต้องอัปโหลด Unity จะสร้างใหม่เอง
ควรแบ่งงานคนละ branch และหลีกเลี่ยงการแก้ฉากเดียวกันพร้อมกัน
