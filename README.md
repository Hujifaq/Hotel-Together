# HotelTogether

โปรเจกต์โรงแรม 3D สำหรับเปิดและพัฒนาต่อใน Unity

เช็กอิน: กด E ให้ลูกค้าคนแรกยื่นเงิน แล้วคลิกเงินจริงเพื่อรับและเช็กอิน คลิกตัว/จับหัวไม่เช็กอินให้อัตโนมัติ มีหลอดเวลารอเริ่มที่ 2 นาที หมดความอดทนแล้วออกจากคิว ดู [Reception.md](Docs/AI/Reception.md)

ระบบป้องกัน: หยิบค้อนข้างชั้นไม้ กดคลิกซ้ายค้างเพื่อกั้นกระจก/ประตู ซ่อม เสริม และถอนไม้ คลิกขวาขณะเล็งจุดป้องกันเพื่อเปลี่ยนงาน คลิกกลอนข้างประตูเพื่อล็อก/ปลดล็อก ดู [คู่มือป้องกันโรงแรม](Docs/AI/HotelDefense.md)

เพิ่มเป้าหมายรายวัน เงินสดที่ลูกค้ายื่นให้ ผลจากการแกล้งลูกค้า อัปเกรดและพนักงานทำความสะอาด กด U เปิดการจัดการ คลิกซ้ายรับเงิน และดูรายงานตอนรุ่งเช้า เงิน/ชื่อเสียง/อัปเกรดบันทึกเมื่อจบวัน ดู [HotelEconomy.md](Docs/AI/HotelEconomy.md)

## เปิดโปรเจกต์

1. ติดตั้ง Unity Editor **6000.6.5f1** ผ่าน Unity Hub
2. Clone repository แล้วเลือก Add project from disk ใน Unity Hub
3. รอ Unity นำเข้าโมเดลและแพ็กเกจ
4. เปิด `Assets/HotelTogether/Scenes/HotelLobby.unity` แล้วกด Play → เข้าเล่น

ใช้ WASD เดิน, Shift วิ่ง, คลิกซ้ายโต้ตอบ/ถือของ, ปล่อยคลิกซ้ายวางของทั่วไป, คลิกขวาโยน, Space กระโดด, J ดูงาน, R เริ่มใหม่ และ Esc พักเกม/เล่นต่อ เครื่องมือกับถาดคลิกหยิบแล้วถือไว้ คลิกซ้ายใช้งาน และ Q วาง ดู [MouseControls.md](Docs/AI/MouseControls.md)
ในเมนูกด Enter เข้าเล่น และ O เปิด Settings & Controls เพื่อปรับความไวเมาส์ เสียง การโยกกล้อง และกลับแกนเมาส์แนวตั้ง ค่าจะถูกจำไว้เมื่อเปิดเกมครั้งต่อไป

ตัวละครมีแอนิเมชันการเคลื่อนไหว งานบริการ แม่บ้าน และต่อสู้ พร้อมมือ first-person ที่เชื่อมการกระทำจริง ดูท่าที่รองรับและขอบเขตการตรวจใน [PlayerAnimations.md](Docs/AI/PlayerAnimations.md)

## สถานะล่าสุด

มีโรงแรมสามชั้น พร้อมระบบหยิบสิ่งของ เข็นรถ นั่ง ประตู และเลือกพนักงาน
โค้ดปัจจุบันมีระบบแขก เช็กอิน งานส่งกระเป๋า/อาหาร/ผ้า งานแม่บ้าน ลิฟต์ และวงจรกลางวัน–กลางคืนพร้อมการป้องกันซอมบี้ ดูคู่มือแต่ละระบบใน `Docs/AI`
ยังไม่มีระบบออนไลน์ รายละเอียดขอบเขตและผลตรวจของการปรับเมนูล่าสุดอยู่ใน [PlayerExperience.md](Docs/AI/PlayerExperience.md)

## ทำงานร่วมกัน

เก็บ Assets พร้อมไฟล์ .meta, Packages, ProjectSettings และ SourceAssets ไว้ใน Git
Library, Temp, Logs และตัวเกมที่ build แล้วไม่ต้องอัปโหลด Unity จะสร้างใหม่เอง
ควรแบ่งงานคนละ branch และหลีกเลี่ยงการแก้ฉากเดียวกันพร้อมกัน

ลูกค้ารองรับการกดคลิกซ้ายค้างบนหัวเพื่อจับ ปล่อยคลิกซ้ายเพื่อปล่อย และคลิกขวาเพื่อโยน พร้อม ragdoll คำบ่น และแอนิเมชันตอบสนองต่อของที่ปาโดน ดู [GuestPhysics.md](Docs/AI/GuestPhysics.md)

ระบบเหตุขัดข้องเพิ่มไฟไหม้ ท่อแตก ลิฟต์เสีย และไฟดับ พร้อมถังดับเพลิง ประแจ ไขควงหุ้มฉนวน งานซ่อมหลายขั้น และแอนิเมชัน ใช้ E หยิบ/กดค้างซ่อม, LMB ฉีดถัง และ J ดูขั้นตอน ดู [MaintenanceIncidents.md](Docs/AI/MaintenanceIncidents.md)


ระบบปืน: อาวุธ 28 กระบอกจากโมเดลที่แนบ อยู่ในห้องเก็บของ G02 คลิกซ้ายหยิบ/ยิง, R รีโหลด, Q วาง และคลิกขวาโยน มีกระสุนจำกัด กล่องเติมกระสุน หลอดเลือดเหนือหัว และการล้มตายตามฟิสิกส์ ดู [FirearmCombat.md](Docs/AI/FirearmCombat.md)

## พนักงานและระบบบริการล่าสุด

มีพนักงานเริ่มต้น 2 คน จ้างเพิ่มได้อีก 6 คน กด U แล้ว MANAGE EMPLOYEES เพื่อกำหนดหน้าที่และพักงาน พนักงานช่วยรับเงิน เช็คอิน เสิร์ฟ ทำความสะอาด ส่งกระเป๋า ซักผ้า และซ่อมเหตุขัดข้อง ดู Docs/AI/Employees.md และ Docs/AI/UtilityRooms.md
